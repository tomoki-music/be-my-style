# 数秘データ自動照合ツール

数秘診断済みデータ（元データA）と、数秘結果を反映したい申込者データなど（データB）を氏名で照合し、
「鍵の数」「魂の数」「使命数」「数秘表記」の4項目をデータBへ一括反映するツールです。

Excel／Googleスプレッドシート上での手作業の検索・コピーをなくすことを目的としています。

## 個人情報保護方針

- **このツールの処理はすべてブラウザ内（クライアントサイド）で完結します。**
- 入力した氏名・メールアドレス・アンケート情報などが外部サーバーへ送信されることはありません。
- サーバーサイド処理・外部API通信は一切行いません。
- `localStorage` / `IndexedDB` への保存は行いません。画面を再読み込みすると入力内容は消えます。
- コンソールへ入力データ全文を出力することはありません。
- ネットワーク通信が発生するのはツール自体（HTML/CSS/JS）の読み込み時のみです。

実データ（顧客の氏名・メールアドレス等）は、このリポジトリやコミット履歴、テストコードに含めないでください。

## 使い方

1. `index.html` をブラウザで開きます（後述の起動方法を参照）。
2. **手順1**: 数秘診断済みのデータA（氏名・鍵の数・魂の数・使命数・数秘表記を含む表）を、
   貼り付けまたはファイルアップロード（CSV/TSV）で読み込みます。
3. **手順2**: 数秘結果を反映したいデータB（氏名列を含む表。他の列は自由）を同様に読み込みます。
4. **手順3**: 照合に使う氏名列・数秘4列を選択します。列名が一般的なもの
   （氏名／お名前／名前／姓名／フルネーム、鍵の数／魂の数／使命数／数秘表記）であれば自動選択されます。
   データBに既に「鍵の数」等の列が存在する場合は、上書きするか新しい列名で追加するかを選べます。
5. **手順4**: 「照合を実行する」を押します。
6. **手順5〜7**: 集計結果（総件数・一致／未一致／重複要確認件数・一致率）、フィルター、
   結果テーブル（行番号表示・横スクロール・ヘッダー固定）を確認します。
7. **手順8**: 結果をCSV/TSVでダウンロード、または「スプレッドシート用にコピー」でクリップボードへコピーできます。
8. **手順9**: 「すべてクリア」で入力・結果をリセットできます（確認ダイアログあり）。

## 氏名照合ルール

表示上の氏名は変更せず、内部的に以下の正規化を行った上で完全一致を判定します。

- Unicode正規化（NFKC）
- 半角スペース・全角スペース・タブ・改行の除去（連続する空白も含む）
- 前後の空白除去

例えば `高橋 扶美` / `高橋　扶美` / `高橋扶美` は同一人物として一致します。

**あいまい一致は行いません。** 漢字・ひらがな・カタカナの自動変換、旧字体・異体字の推測一致は実装していません。
異なる氏名（異なる漢字、苗字のみ一致、名前のみ一致など）は一致しません。

## 同姓同名（重複）への対応

元データAに、正規化後の氏名が同じ行が複数存在する場合、その氏名は「重複・要確認」として扱い、
**数秘4項目は自動反映しません**（誤って先頭の1件を採用することはありません）。
結果テーブルでは薄いオレンジ色の背景で表示され、候補件数（何件ヒットしたか）も表示されます。

## CSV / TSV の対応

- カンマ区切り(CSV)・タブ区切り(TSV)の両方に対応し、内容から自動判定します（拡張子 `.tsv` は強制的にタブ区切りとして扱います）。
- セル内の改行・カンマ・ダブルクォート（`"..."` によるクォート、`""` エスケープ）を正しく解釈・出力します。
- ダウンロードするCSV/TSVはUTF-8 BOM付きで出力するため、Excelで開いても日本語が文字化けしません。
- データBの既存列・列順は変更せず、末尾に数秘4列＋照合ステータス列を追加します。

## 動作環境

- サーバーサイド処理・外部API通信なしの静的HTML/CSS/JavaScriptです。
- PCブラウザでの利用を優先していますが、スマートフォンでも最低限閲覧・操作できます。
- 数百〜数千件程度のデータで快適に動作するよう、氏名照合はA側をMap化した1回走査（O(N+M)）で行っています。

## 起動方法（ローカル）

ビルド不要です。`index.html` をブラウザで直接開くだけで動作します。

```bash
open tools/numerology-data-matcher/index.html
```

または簡易サーバーを立てて開くこともできます。

```bash
cd tools/numerology-data-matcher
python3 -m http.server 8000
# http://localhost:8000/ をブラウザで開く
```

## GitHub Pages等への公開方法（任意）

このディレクトリはサーバーサイド処理を持たない静的サイトなので、GitHub Pages等でそのまま公開できます。
公開する場合は、リポジトリの用途・公開範囲を踏まえて事前に判断してください（本ツールの導入時点では未設定です）。

代表的な方法:

- GitHub の Settings → Pages で、Source を「Deploy from a branch」にし、
  公開したいブランチ・フォルダ（例: `main` ブランチの `/tools/numerology-data-matcher`）を指定する
  （GitHub Pagesはリポジトリルートまたは `/docs` フォルダのみ選択できるため、そのままでは指定できません。
  公開する場合は `gh-pages` ブランチを作るか、GitHub Actions（`actions/deploy-pages`）でこのディレクトリのみを
  デプロイするワークフローを別途用意する必要があります）。
- あるいは、このツールだけを別リポジトリに切り出して公開する方法もあります。

## テスト

氏名正規化・照合ロジック・CSV/TSV解析は Node.js の組み込みテストランナー（`node:test`）でユニットテストしています。

```bash
cd tools/numerology-data-matcher
node --test tests/
```

DOM操作・ファイル読込・列選択・照合実行・フィルター・ダウンロード等のブラウザ上の動作は、
実装時にPuppeteer（実Chromeブラウザ）を用いて手動で確認済みです（本ディレクトリにブラウザテストのコードは含めていません）。

## 実装時の注意点（このツールを改修する場合）

- 入力データをHTMLへ表示する際は `textContent` のみを使用し、`innerHTML` へ入力データを直接挿入しないでください（XSS対策）。
- ダウンロード用の Blob URL は使用後に `URL.revokeObjectURL()` で解放してください。
- 氏名・メールアドレス等の個人情報をテストコードやコミットへ直接記載しないでください。
